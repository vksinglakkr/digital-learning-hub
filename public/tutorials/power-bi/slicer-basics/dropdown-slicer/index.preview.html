Module 2 • Practical Problem

Vertical List Se Dashboard Kyun Kharaab Hota Hai?

Power BI mein by default slicer ek lambi vertical checkbox list banata hai. Isse aamtaur par 3 badi samasyayein aati hain:

1. Canvas Space Ki Barbaadi

Agar 10 ya 15 cities hain, toh vertical list adha screen gher leti hai aur zaroori sales charts ke liye jagah nahi bachti.

2. Bura Scrollbar Experience

Slicer ke andar chhota sa scrollbar ban jata hai, jisse user ko niche ke options dekhne ke liye bar-bar scroll karna padta hai.

3. Dropdown Solution

Dropdown chunne par sabhi options ek click par pop-up menu mein khulte hain aur normal halat mein sirf 1 line space lete hain!

Module 2 • Relatable Context

Aura Retail Ki Samasya Aur Slicer Solution

Real-world business case: management ko report dekhne mein kya bottleneck tha aur Slicers lagane ke baad dashboard kaise badal gaya.

❌ Pehle (Before Slicers)

Static Cluttered 20-Column Table

Management ko har regional meeting ke liye 4 alag-alag report pages banane padte the. Agar CEO ko sirf South Region ke Electronics dekhne hote the, toh unhe poore Excel sheet mein scroll karke manually totals nikaalne padte the.

  • Reports bahut heavy aur slow ho jaati thi
  • Users dashboard par click karke explore nahi kar pate the
  • Target compare karna mushkil tha
✅ Baad Mein (After Slicers)

Interactive Self-Service Dashboard

Ek hi single page report par top horizontal buttons, category dropdowns aur date sliders laga diye gaye. Ab CEO ek click mein North, South ya koi bhi custom date range filter kar sakte hain.

  • 1 single report ne 4 purane pages ko replace kar diya
  • Edit interactions se company targets stable rahe
  • Zero formula recalculation lag: Instant app-like speed

Module 6 • Interactive Challenge

अब आप खुद करके देखिए! (Hands-on Mission)

Aura Retail Dashboard Optimization Challenge: niche diye gaye 5 tasks ko complete karein aur checklist tick karein.

Mission Progress 0% Completed (0/5 Tasks)
Task 1: Region Slicer ko standard List se badalkar Horizontal Tile (Button) layout mein set karein.
Task 2: Format visual > Selection settings mein jakar "Show Select all" option ko enable karein.
Task 3: Category Dropdown ke 3-dots menu se Search bar on karein aur "Electronics" type karke filter karein.
Task 4: Format ribbon se Edit Interactions activate karein aur Annual Target Card ko 'None (🚫)' par lock karein.
Task 5: View ribbon se Sync Slicers pane open karein aur Page 1 ke slicer ko Page 2 ke sath sync karein.
🎉 शाबाश! आपने Power BI Slicers के सभी 5 प्रैक्टिकल मिशन सफलतापूर्वक पूरे कर लिए हैं!
